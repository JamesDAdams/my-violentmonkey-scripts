Steam — AI disclosure

Steam

Steam requires developers to disclose generative-AI use. This script brings that disclosure where you actually look: on the game page, and on every thumbnail across the store.

  • An “AI” row in the glance box of each game page, with one tag per declared use (graphics, voices, translation, code, in-game AI…).
  • An “AI” badge on thumbnails in search, home, tags and sales; declared uses appear in the tooltip.
  • Classification and 30-day cache run locally — no account, no third-party service.

Discord — Invite → open tab

Discord

On a Discord invite page, the usual flow loads Discord in the current tab — login screen included. This script adds a button that sends the invite straight to the Discord tab you already have open, already logged in.

  • A “Send to my Discord tab” button under “Create Account”, on discord.com/invite/… and discord.gg/…
  • The invite code travels through the userscript storage, then your Discord tab opens the invite and takes focus.
  • No network request and no analytics: everything stays between your two tabs.
Install Details

Requires an open Discord tab · v4.0

Steam — Region + key price

Steam

Two badges on the purchase box: the Steam price of the country you pick, and the cheapest key price on GG.deals. DLC rows get them too.

  • Choose any country for the Steam price — Argentina, Turkey, the US… — and any region for key prices.
  • The key price comes from GG.deals with your own free API key; badges link straight to SteamDB and GG.deals.
  • Your key and your regions stay inside the script, on your computer.
Install Details

GG.deals API key required for key prices · v4.0
